# Project 1: Kenyan Bank Peer Dashboard

A comparison of six Kenyan banks on profitability, efficiency,
asset quality and capital, built with public data only.

**Banks:** KCB, Equity, Stanbic, Co-operative, I&M (listed) and
Sidian (unlisted, mid-tier)

**Status:** Data collection

## Questions this project answers

1. **Profitability:** Which bank earns the highest return on equity,
   and is the gap between the large banks and Sidian widening or
   narrowing over the last 3 to 5 years?
   *(KPI: ROE)*
2. **Margin:** How does net interest margin compare, and do the
   large banks' cheaper deposits give them an advantage?
   *(KPI: NIM)*
3. **Efficiency:** Who spends the least to earn a shilling of income,
   and does a lower ratio go with higher ROE?
   *(KPI: cost-to-income)*
4. **Asset quality:** How do NPL ratios compare, and does a
   SME-focused lender carry more bad loans than corporate-heavy banks?
   *(KPI: NPL ratio)*
5. **Capital:** Which banks hold the most headroom above the
   regulatory minimum, and does it cost them returns?
   *(KPI: CAR)*
6. **Overall:** Which bank looks strongest, and which looks most exposed?

## Method

All figures are taken at group level for the same financial years.
Sources are listed in `data/README.md`.
